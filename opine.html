Opine

Opine is a passion project I created and maintain (with Claude): a paper where anybody can write about anything. Pick a pen name and publish. There is no account to make and no email to give.

It is built on broadsheet, the software I wrote to run it, which sets writing out like the front page of a newspaper. If you are looking to start a blog by yourself, with your friends, or for anybody, broadsheet might be a good choice! It is not public yet, so reach out if you would like to try it.
